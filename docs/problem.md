# Problem Statement

## Overview

I am a **Logical Reasoning Tutor** who needs to explain patterns to students.

Help me create an app that will have **sections for different patterns**. The site should be colourful and should explain the answers to questions after clicking the **"Display Answer"** button.

---

## Features Required

### Pattern Categories

The site should include sections for the following types of pattern questions:

1. **Number Series** – Guess the next number in the series
   - Example: `2, 4, 6, 8, ?`

2. **Shape Sequences** – Guess the next shape in the sequence

3. **Alphabet Sequences** – Guess the next alphabet in the sequence

### Difficulty Levels

- Good to have **different difficulty levels** (Easy / Medium / Hard) within the site

### Answer Reveal

- Each question should have a **"Display Answer"** button that, when clicked, shows the answer along with an explanation of the pattern

---

## Deployment

- Deploy the site on **Vercel**
